# 時点を起こす者と、画面

軸を時系列に歩き、各時点の意思決定者を決める。人が見て判断するなら画面、推論（LLM）が判断するなら agent、事実に反応する決まりは規則。

## 見極め方
- 迷ったら「その時点の意思決定者は誰か」に戻る
- 誰の画面か。役者が変わるなら、同じ時点の 2 枚目ではなく別の時点
- 規則は「◯◯が起きたら△△する」と言える。言えないなら推論（agent）か人の判断（画面）
- 画面は、意思決定に要る情報を見て行動する場所。一覧＋詳細＋CRUD で済ませない

## 落とし穴
- 画面の中身を語れない — 「◯◯管理画面」で止まるのは、その時点を掴めていない合図
- 1 つの操作が続けて起こす 2 枚目の事実に、規則や agent を発明する — 1 つのコマンドの events に並べる
- 生産者を発明する — 「◯◯を検知する」型の規則が合図。外部の人やシステムが起こす事実は、その役者の画面とコマンドで起こす
- 時間をイベントにする（締切日になった） — 規則は義務を生んだ事実を聴き、評価の時刻は例の「時刻」に書く
